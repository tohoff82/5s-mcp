# 🔍 Чек-лист Самореферентної Безпеки

## Перед початком БУДЬ-ЯКОЇ 5S процедури

### 1. Попередня Перевірка ✅
- [ ] Система працює нормально (всі сервіси активні)
- [ ] Достатньо місця для backup (мінімум 2GB вільного)
- [ ] Користувач підтвердив виконання процедури
- [ ] Прочитано повний документ про засоби захисту

### 2. Backup та Захист ✅
- [ ] Створено повний backup ui-agent системи
- [ ] Перевірено цілісність backup файлу
- [ ] Backup збережено поза межами ui-agent директорії
- [ ] Записано час створення backup для відкату

### 3. Аналіз Ризиків ✅
- [ ] Ідентифіковано всі файли/директорії для зміни
- [ ] Перевірено, чи не містять вони критичні компоненти
- [ ] Виключено власні файли агента з операцій видалення
- [ ] Переконано, що операції не впливають на активні сервіси

### 4. Безпечне Виконання ✅
- [ ] Виконано dry-run симуляцію
- [ ] Показано користувачу список планованих змін
- [ ] Отримано явне підтвердження
- [ ] Операції виконуються поетапно з паузами

### 5. Контроль Процесу ✅
- [ ] Після кожного кроку перевіряється працездатність
- [ ] Моніториться стан ui-agent сервісів
- [ ] Перевіряється доступність RabbitMQ та MongoDB
- [ ] Відстежуються помилки у логах

### 6. Завершення ✅
- [ ] Всі операції завершені успішно
- [ ] Система працює нормально
- [ ] Створено звіт про виконані зміни
- [ ] Backup залишено для можливого відкату

## 🚨 ПЛАН "ЧЕРВОНОЇ КНОПКИ"

Якщо щось пішло не так - НЕГАЙНО:

1. **ЗУПИНИТИ** всі поточні операції
2. **НЕ ПАНІКУВАТИ** - backup існує
3. **ВІДНОВИТИ** систему з backup
4. **ПОВІДОМИТИ** користувача про проблему
5. **ПРОАНАЛІЗУВАТИ** причину збою

## Команди Екстреного Відновлення

```bash
# УВАГА: Використовувати тільки в екстренних випадках!
systemctl stop ui-agent-*
cd /root
mv ui-agent ui-agent-broken-$(date +%Y%m%d-%H%M%S)
tar -xzf /backup/ui-agent-backup-[останній].tar.gz
systemctl start ui-agent-*
```

## Контактна Інформація

У випадку критичних проблем:
- Повідомити користувача через доступні канали
- Створити детальний звіт про збій
- Зберегти всі лог файли для аналізу
