# Seiri: Аналіз файлової системи

## Guided Reasoning Schema

### 1. ASSESS (Оцінити поточний стан)
```
router_monitor({ action: "disk" })
router_files({ action: "find", path: "/", options: { size: "+100M", type: "f" }})
router_files({ action: "find", path: "/home", options: { atime: "+30", type: "f" }})
router_files({ action: "find", path: "/tmp", options: { mtime: "+7", type: "f" }})
```

**Питання для аналізу:**
- Які файли займають найбільше місця?
- Які файли не відкривалися 30+ днів?
- Чи є в /tmp старі файли?
- Чи є дублікати великих файлів?

### 2. CATEGORIZE (Категоризувати)

**KEEP** (Зберегти):
- Активні конфіги сервісів
- Бази даних (MongoDB)
- Логи останніх 7 днів
- SSL сертифікати
- SSH ключі
- Активний код проектів

**QUARANTINE** (Карантин /root/.5s-quarantine/):
- Файли не відкривались 7-30 днів
- Старі backup файли
- Завантажені архіви
- Тимчасові скрипти

**DELETE** (Видалити):
- Файли не відкривались 30+ днів (крім системних)
- Порожні директорії
- Тимчасові файли старші 7 днів
- Логи старші місяця

### 3. EXECUTE (Виконати)

#### 3.1 Створити карантин
```bash
mkdir -p /root/.5s-quarantine/$(date +%Y-%m-%d)
```

#### 3.2 Переміщення в карантин (7-30 днів)
```bash
find /root -atime +7 -atime -30 -type f -size +10M -exec mv {} /root/.5s-quarantine/$(date +%Y-%m-%d)/ \;
```

#### 3.3 Видалення старих файлів (30+ днів)
```bash
# УВАГА: Тільки після ретельної перевірки!
find /tmp -mtime +7 -delete
find /var/tmp -mtime +7 -delete
# НЕ ЧІПАТИ системні директорії без явного дозволу!
```

### 4. VERIFY (Перевірити)
```
router_monitor({ action: "disk" })
router_system({ action: "health" })
```

**Перевірити:**
- Сервіси працюють нормально
- Простір звільнено
- Логи записуються

### 5. DOCUMENT (Задокументувати)

Створити звіт:
- Скільки простору звільнено
- Які файли переміщені/видалені
- Чи виникли проблеми
- Рекомендації на майбутнє

## Критерії успіху
- [ ] Проаналізовано використання диску
- [ ] Створено карантин для сумнівних файлів  
- [ ] Видалено очевидно непотрібні файли
- [ ] Сервіси працюють після очищення
- [ ] Документовано результати
