# 1-S: Seiri (整理) - Сортування/Відбір

## Мета
Видалити з сервера все непотрібне, залишити тільки те, що дійсно використовується для поточних задач.

## Принцип "Червоного мітки"
Все, що не використовувалося останні 30 днів → кандидат на видалення
Все, що не використовувалося останні 7 днів → переміщення в карантин

## Процедури
1. `files-analysis.md` - Аналіз файлової системи
2. `packages-cleanup.md` - Очищення пакетів
3. `logs-retention.md` - Управління логами
4. `processes-audit.md` - Аудит процесів
5. `storage-optimization.md` - Оптимізація сховища

## Очікуваний результат
- Звільнено мінімум 500MB дискового простору
- Видалено всі невикористовувані пакети
- Логи оптимізовані за розміром
- Документовані рішення про збереження/видалення
