## Команди для швидкого виконання

### Швидкий системний огляд:
```bash
echo "=== 5S Quick Status ==="
df -h /
free -h  
systemctl is-active ui-agent-claude ui-agent-telegram ui-agent-tools mongodb rabbitmq-server caddy
uptime
```

### Швидке очищення:
```bash
# Temp files cleanup
find /tmp -mtime +1 -delete 2>/dev/null
find /root/temp -mtime +1 -delete 2>/dev/null

# APT cleanup  
apt autoremove -y && apt autoclean

# Memory cache drop (if needed)
sync && echo 3 > /proc/sys/vm/drop_caches
```

### Швидкий health check:
```bash
# Check all UI-Agent services
for svc in claude telegram tools reference-api webapp ssh-monitor; do
  echo "ui-agent-$svc: $(systemctl is-active ui-agent-$svc)"
done
```
